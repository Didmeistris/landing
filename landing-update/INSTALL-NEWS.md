# Установка обновления новостей и валют

В комплекте полный `index.html` с встроенными контроллерами новостей и тарифов.

## Важно
Загрузка ZIP-файла в репозиторий не устанавливает обновление: GitHub не распаковывает архивы автоматически. Нужно распаковать комплект на компьютере и заменить сами файлы проекта, включая workflow.

## GitHub Pages
1. Заменить `index.html`, `app.js`, `vite.config.js` и `.github/workflows/deploy.yml`.
2. Добавить папки `public`, `scripts`, `tests`, файлы `news.js`, `pricing.js`, `.gitignore` из комплекта.
3. Отправить изменения в main. В Settings → Pages источником должен быть GitHub Actions.
4. В Actions → Deploy to GitHub Pages проверить результат. Run workflow запускает сбор сразу.

Workflow собирает новости и курс ЦБ каждый час, а также после полуночи в Москве. Расписание GitHub может задерживаться; в публичных репозиториях оно может отключаться после длительного отсутствия активности. Посетитель перечитывает готовые данные со своего домена, без публичных CORS-прокси.

## Новости
Честный ЗНАК: реальная официальная лента оператора ЦРПТ — https://crpt.ru/news/. Текшер: https://main.teksher.kg/news.html. У каждого сообщения ссылка на конкретную публикацию и дата, если она есть у источника. У Текшер у многих публикаций дата отсутствует — она не придумывается.

При отказе источника сохраняются последние успешно собранные публикации через кеш Actions; показывается сообщение о сбое. Если кеш отсутствует, недоступность обозначается прямо. Блок и подписи поддерживают RU/EN/KG, сами заголовки остаются на языке официальной публикации.

## Тарифы
Русский язык → RUB, английский → USD, кыргызский → KGS. В любой версии можно выбрать другую валюту.

Курс запрашивается у ЦБ РФ по текущему дню в часовом поясе Europe/Moscow: XML_daily.asp?date_req=ДД/ММ/ГГГГ. Учитывается номинал валюты: курс KGS публикуется за 100 сомов. В выходной отображается официальный курс, действующий на выбранный день, с датой его вступления в силу.

Исходные цены в рублях: 23290 / 62990 / 111990 / 194990 за 1 / 3 / 6 / 12 месяцев. Конвертация округляется вверх. Разница от исходной рублёвой цены составляет от 0 до +100 рублей за весь тариф по применённому курсу ЦБ. Красивые целые цены и окончания 99 используются только если укладываются в этот предел. Комиссии обмена банка не входят в математический пересчёт.

Математика сборщика использует Decimal, клиент проверяет предел через целые числа BigInt. Если курс не проверен на текущий московский день, валютные цены не показываются: остаются рубли и понятное пояснение. На смене дня браузер сразу перестаёт использовать вчерашний пересчёт, даже если посетитель не перезагрузил страницу. Обновляются карточки, месячные эквиваленты, FAQ и ответ бота о стоимости.

## Ручное размещение без сборки
Для обычного HTTP-хостинга скопировать `public/news.json` и `public/pricing.json` рядом с `index.html`; оставить папку images. Для регулярного обновления всё равно нужен периодический запуск обоих сборщиков. Открытие HTML через file:// не подходит для загрузки JSON.
